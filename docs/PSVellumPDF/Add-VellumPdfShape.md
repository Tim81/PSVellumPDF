# Add-VellumPdfShape

## SYNOPSIS

Draws a rectangle, ellipse, arc or line on a page of a page-based document.

## SYNTAX

### __AllParameterSets

```
Add-VellumPdfShape [-Shape] <string> -Document <PdfDocument> -X <double> -Y <double> [-Page <int>]
 [-Width <double>] [-Height <double>] [-X2 <double>] [-Y2 <double>] [-Radius <double>]
 [-StartAngle <double>] [-EndAngle <double>] [-IccProfilePath <string>] [-FillIcc <double[]>]
 [-StrokeIcc <double[]>] [-FillColor <Object>] [-FillCmyk <double[]>] [-FillGray <double>]
 [-StrokeColor <Object>] [-StrokeCmyk <double[]>] [-StrokeGray <double>] [-StrokeWidth <double>]
 [-Dash <double[]>] [-Opacity <double>] [-StrokeOpacity <double>] [-LineCap <string>]
 [-LineJoin <string>] [-MiterLimit <double>] [-AltText <string>] [<CommonParameters>]
```

## DESCRIPTION

Coordinates are PDF points from the page's bottom-left corner (72 pt = 1
inch).
Rectangle and Ellipse take the lower-left corner (-X, -Y) and the
size (-Width, -Height); an ellipse is inscribed in that box.
A Line runs
from (-X, -Y) to (-X2, -Y2).
An Arc is part of a circle: (-X, -Y) is the centre,
-Radius its size, and -StartAngle/-EndAngle (degrees, counter-clockwise from 3
o'clock) the span; it is stroked, and a fill paints the segment between the arc
and its chord.

Colours are RGB triples in 0..1, hex ('#3366cc') or names; for CMYK use
-FillCmyk / -StrokeCmyk with four values in 0..1.
For colour-managed output give an
ICC profile with -IccProfilePath and the colour in that profile's components with
-FillIcc / -StrokeIcc (1, 3 or 4 values in 0..1 for a Gray, RGB/Lab or CMYK profile).
A shape with neither a
fill nor a stroke is stroked in black; a line is always stroked.
Opacity is
0 (transparent) to 1 (opaque).

## EXAMPLES

### EXAMPLE 1

$doc | Add-VellumPdfShape Rectangle -X 72 -Y 600 -Width 200 -Height 80 -FillColor '#e8f0fe' -StrokeColor navy

### EXAMPLE 2

$doc | Add-VellumPdfShape Line -X 72 -Y 590 -X2 523 -Y2 590 -StrokeWidth 2 -Dash 6,3

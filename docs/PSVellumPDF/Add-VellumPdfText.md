# Add-VellumPdfText

## SYNOPSIS

Places a line of text at x/y on a page of a page-based document.

## SYNTAX

### __AllParameterSets

```
Add-VellumPdfText [-Text] <string> -Document <PdfDocument> -X <double> -Y <double> [-Page <int>]
 [-FontSize <double>] [-Font <string>] [-FontHandle <EmbeddedFontHandle>] [-Color <Object>]
 [-Align <string>] [-CharSpacing <double>] [-WordSpacing <double>] [-Rise <double>]
 [-HorizontalScale <double>] [-Rotation <double>] [-Role <string>] [-Language <string>]
 [<CommonParameters>]
```

## DESCRIPTION

Draws one line (no wrapping) with its baseline starting at (-X, -Y), in
points from the page's bottom-left.
-Align Center/Right positions the text
about x instead.
Use a base-14 font by name (-Font), or an embedded
TrueType font (-FontHandle from Register-VellumPdfFont) for Unicode text.

In a PDF/A document base-14 text is embedded automatically with a
metric-compatible Liberation font (VellumPdf.Fonts.Standard14), as PDF/A
forbids non-embedded fonts.
A tab is drawn as four spaces (a tab has no glyph in a PDF font).
For several lines of wrapped text use the
flow-layout document (New-VellumPdfDocument).

## EXAMPLES

### EXAMPLE 1

$doc | Add-VellumPdfText 'Invoice 2026-001' -X 72 -Y 760 -FontSize 18 -Font HelveticaBold

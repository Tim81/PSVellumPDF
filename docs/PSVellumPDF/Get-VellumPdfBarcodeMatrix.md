# Get-VellumPdfBarcodeMatrix

## SYNOPSIS

Returns the module (black/white square) matrix of a 2-D barcode, without drawing it.

## SYNTAX

### Text (Default)

```
Get-VellumPdfBarcodeMatrix [-Type] <string> [-Content] <string> [-ErrorCorrection <string>]
 [-QrVersion <int>] [-QrMask <int>] [-TextEncoding <string>] [-QrGs1 <string>] [-Gs1]
 [-Shape <string>] [-AztecFormat <string>] [-AztecErrorCorrectionPercent <int>] [-Columns <int>]
 [-Rows <int>] [-Compact] [-ErrorCorrectionLevel <int>] [<CommonParameters>]
```

### Bytes

```
Get-VellumPdfBarcodeMatrix [-Type] <string> -Bytes <byte[]> [-ErrorCorrection <string>]
 [-QrVersion <int>] [-QrMask <int>] [-TextEncoding <string>] [-QrGs1 <string>] [-Gs1]
 [-Shape <string>] [-AztecFormat <string>] [-AztecErrorCorrectionPercent <int>] [-Columns <int>]
 [-Rows <int>] [-Compact] [-ErrorCorrectionLevel <int>] [<CommonParameters>]
```

## DESCRIPTION

Encodes the content with the same validation and options as Add-VellumPdfBarcode and
returns the symbol as data: its size and every row as text ('#' dark, '.' light).
Use it to show a QR code in a console, to compare symbols in tests, or to render the
symbol with another tool.
Supported: QrCode, MicroQrCode, DataMatrix, Aztec, Pdf417.
The matrix has no quiet zone.

## EXAMPLES

### EXAMPLE 1

(Get-VellumPdfBarcodeMatrix QrCode 'hello').Rows

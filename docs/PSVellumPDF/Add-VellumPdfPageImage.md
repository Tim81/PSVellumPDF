# Add-VellumPdfPageImage

## SYNOPSIS

Places an image at x/y on a page of a page-based document.

## SYNTAX

### Path (Default)

```
Add-VellumPdfPageImage [-Path] <string> -Document <PdfDocument> -X <double> -Y <double>
 [-Page <int>] [-Width <double>] [-Height <double>] [-AltText <string>] [-Decorative]
 [-Rotation <double>] [<CommonParameters>]
```

### Bytes

```
Add-VellumPdfPageImage -Document <PdfDocument> -ImageBytes <byte[]> -Format <string> -X <double>
 -Y <double> [-Page <int>] [-Width <double>] [-Height <double>] [-AltText <string>] [-Decorative]
 [-Rotation <double>] [<CommonParameters>]
```

## DESCRIPTION

Loads a JPEG, PNG, BMP, GIF, TIFF, JBIG2 or JPEG 2000 image (from -Path or
from -ImageBytes with -Format) and draws it with its lower-left corner at
(-X, -Y), in points from the page's bottom-left.
Give -Width, -Height or
both: with one the aspect ratio is kept; with neither the image is drawn at
one pixel per point.
For load options (16-bit reduction, raster decoding) or
CCITT fax data use the flow-layout Add-VellumPdfImage.

In a tagged page document (New-VellumPdfPageDocument -Tagged, PdfA2a or PdfUA1)
every image needs -AltText, or -Decorative to be treated as an artifact.

## EXAMPLES

### EXAMPLE 1

$doc | Add-VellumPdfPageImage ./logo.png -X 72 -Y 740 -Width 120

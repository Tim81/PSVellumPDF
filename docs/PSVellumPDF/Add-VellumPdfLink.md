# Add-VellumPdfLink

## SYNOPSIS

Makes a rectangle on a page a clickable link to a URL or to another page.

## SYNTAX

### __AllParameterSets

```
Add-VellumPdfLink [-Document] <PdfDocument> [[-Page] <int>] [-X] <double> [-Y] <double>
 [-Width] <double> [-Height] <double> [[-Uri] <string>] [[-TargetPage] <int>] [[-DestLeft] <double>]
 [[-DestTop] <double>] [[-Flags] <PdfAnnotationFlags>] [<CommonParameters>]
```

## DESCRIPTION

Adds a link annotation over the rectangle (-X, -Y, -Width, -Height), in
points from the page's bottom-left.
With -Uri the link opens a web address
(http, https or mailto only).
With -TargetPage it jumps to another page of
the document, optionally to the point (-DestLeft, -DestTop) on it - something
the flow-layout document cannot do.

The link rectangle is invisible; draw something under it (text, a shape) or
use -Border to show a thin frame.
Annotation flags default to Print.

## EXAMPLES

### EXAMPLE 1

$doc | Add-VellumPdfLink -X 72 -Y 700 -Width 120 -Height 14 -Uri https://example.com

### EXAMPLE 2

$doc | Add-VellumPdfLink -Page 1 -X 72 -Y 650 -Width 90 -Height 14 -TargetPage 3

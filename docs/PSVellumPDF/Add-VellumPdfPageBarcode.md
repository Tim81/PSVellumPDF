# Add-VellumPdfPageBarcode

## SYNOPSIS

Draws a barcode or 2-D symbol at x/y on a page of a page-based document.

## SYNTAX

### Text (Default)

```
Add-VellumPdfPageBarcode [-Type] <string> [-Content] <string> -Document <PdfDocument> -X <double>
 -Y <double> [-Page <int>] [-ModuleSize <double>] [-TargetWidth <double>] [-Foreground <Object>]
 [-Background <Object>] [-NoQuietZone] [-BarHeight <double>] [-ShowText <bool>] [-TextSize <double>]
 [-TextFont <string>] [-ErrorCorrection <string>] [-QrVersion <int>] [-QrMask <int>]
 [-TextEncoding <string>] [-QrGs1 <string>] [-Gs1] [-Shape <string>] [-AztecFormat <string>]
 [-AztecErrorCorrectionPercent <int>] [-Columns <int>] [-Rows <int>] [-Compact]
 [-ErrorCorrectionLevel <int>] [-PreferredAspectRatio <double>] [-RowHeight <double>] [-CheckDigit]
 [-FullAscii] [-WideNarrowRatio <double>] [-AddOn <string>] [-BearerBars <string>]
 [-AltText <string>] [-Decorative] [<CommonParameters>]
```

### Bytes

```

 -Y <double> [-Page <int>] [-ModuleSize <double>] [-TargetWidth <double>] [-Foreground <Object>]
 [-Background <Object>] [-NoQuietZone] [-BarHeight <double>] [-ShowText <bool>] [-TextSize <double>]
 [-TextFont <string>] [-ErrorCorrection <string>] [-QrVersion <int>] [-QrMask <int>]

 [-FullAscii] [-WideNarrowRatio <double>] [-AddOn <string>] [-BearerBars <string>]
 [-AltText <string>] [-Decorative] [<CommonParameters>]
```

## DESCRIPTION

The page-document counterpart of Add-VellumPdfBarcode, with the same
symbologies and options (QrCode, MicroQrCode, DataMatrix, Aztec, Pdf417,
Code128, Code39, Ean13, Ean8, UpcA, UpcE, Itf14) and the same validation:
content that cannot be encoded fails here.
The symbol's lower-left corner,
including its quiet zone, is placed at (-X, -Y).
Size it with -ModuleSize or
-TargetWidth.
In a tagged page document the symbol is a Figure with -AltText
(default: the symbology and content), or an artifact with -Decorative.

In a PDF/A page document the human-readable line of a 1-D barcode is off by
default and -ShowText is refused, because it would need a non-embedded font.

## EXAMPLES

### EXAMPLE 1

$doc | Add-VellumPdfPageBarcode QrCode 'https://example.com' -X 72 -Y 600 -TargetWidth 90
